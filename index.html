Process Analysis (P01)

The first major project/assignment for my IAT-339 class was to make a style guide using the concepts of HTML and CSS we had learned up to that point. This was a solo project that we had 2 weeks to complete, with a checkpoint in the middle of the week to get feedback and direction. The problem I had to tackle here was getting familiar with certain coding concepts that I wasn't yet familiar with at that point, such as forms and buttons, as well as padding in the context of CSS. That being said, these were all fairly easy to understand considering their place in the courseflow, and it helped me learn and get used to coding in HTML and CSS, which would become necessary for later projects.
